## 📖 Overview

**Job Application Tracker** is a lightweight, client-side web app for organizing and tracking job applications. Add jobs, update their status (Applied, Interview, Offer, Rejected), and keep your job hunt organized — all stored locally in your browser via `localStorage`.

> **Live at** → [https://imoloy.github.io/B13-A4](https://imoloy.github.io/B13-A4)

---

## 🛠️ Technologies Used

| Technology | Purpose |
|---|---|
| **HTML5** | Page structure |
| **Tailwind CSS** | Utility-first responsive styling |
| **JavaScript (ES6+)** | Application logic and DOM manipulation |
| **localStorage** | Persistent client-side data storage |

---

## ✨ Core Features

- **Add Applications** — Log job title, company, and application date
- **Status Tracking** — Update each application through stages: Applied → Interview → Offer / Rejected
- **Persistent Storage** — All data saved in `localStorage`; survives page refresh
- **Delete Entries** — Remove applications from your board
- **Responsive UI** — Clean layout that works on mobile and desktop

## 🚀 Run Locally

1. **Clone the repository**

   ```bash
   git clone https://github.com/iMoloy/B13-A4.git
   cd B13-A4
   ```

2. **Open in browser**

   ```bash
   open index.html
   # or
   npx serve .
   ```

No build step or `npm install` required.
